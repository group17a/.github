# Contributing

Thank you for looking. Pull requests and issues are welcome on any public 17A repository unless its README says otherwise.

A few rules hold across the organization:

- **Plain language.** User-facing text is written for a skeptical, non-technical reader. No em dashes, no marketing vocabulary.
- **Every claim carries a source.** A number without a source, or a negative statement without a date and a citation, will not be merged.
- **Absence of evidence is never proof.** "We could not verify X" is acceptable. "X is false" needs a record that says so.
- **Code decides.** Where a repository computes a verdict, tier, or score, that logic stays in plain code over typed data. Pull requests that let model output change an outcome will not be merged.
- **Tests travel with changes.** If you change behavior, change or add the test in the same pull request.

A repository's own CONTRIBUTING.md adds to these rules and takes precedence where they differ.
