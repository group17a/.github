# 17A

We are a consulting firm that works with state and local governments: city halls, county IT shops, state agencies, and the nonprofits that work alongside them. The work is health, economic mobility, public safety, shared services, and data and technology. Most of it is confidential. This is where the parts that can be public live: the papers that came out of the work, the models behind them, and the tools we build for public servants.

## How we build

- **Plain language for skeptical readers.** The audience is a city council, a state CIO, or a federal reviewer. They get conclusions, not methods.
- **Every number traces to a source.** If it cannot, the page says so.
- **Code decides; models assist.** Where a tool reaches a conclusion, plain code computes it over typed data. Models do research and drafting, and nothing inside an input can change the outcome.
- **The methodology is public and matches the code.** When a rule changes, the document changes in the same commit.
- **Built with AI, owned by people.** Claude Code does most of the typing. We are accountable for what ships.
