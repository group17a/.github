# Security

## Reporting a vulnerability

Email security@group17a.com. We acknowledge reports within 3 business days. Please do not open public issues for exploitable vulnerabilities.

## Scope

This policy applies to every public repository in the 17A organization unless a repository carries its own SECURITY.md, which then takes precedence. Several of our tools take attacker-authored input (vendor pitches, public web pages, government records), so reports that show an input changing an outcome it should not be able to change are especially welcome.
